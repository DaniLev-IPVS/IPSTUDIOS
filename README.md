# IP Studios

Monetizing IP and scaling internet trends.

Next.js 15 + Tailwind 4 site for IP Studios. Branding and copy come from the 2026 investor deck and the Branding Mark I brand kit, summarized in [`docs/brand`](docs/brand/BRAND.md).

```bash
npm install
npm run dev
```

- `docs/brand/BRAND.md` — palette, type, and slide-by-slide content reference
- `docs/brand/IP-Studios-Deck-2026.pdf` — source deck
- `src/content.ts` — structured copy from the deck
- `src/app/globals.css` — brand tokens (DM Serif Display + Archivo, wine radial)
- `src/components/Logo.tsx` — Branding Mark I lockups as inline SVG (primary, horizontal, inline, monogram)
- `public/brand/` — static SVG exports of every lockup and color way
